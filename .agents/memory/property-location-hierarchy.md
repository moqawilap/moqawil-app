---
name: Property location hierarchy
description: Distinguishes exact property locations from service-provider coverage.
---

Property registrations select one exact location through governorate, then wilayat, then area. They must not reuse the multi-wilayat or all-Oman service coverage controls.

**Why:** A service can cover many wilayats, but a physical property exists in one precise area. Mixing the two models creates misleading property search results.

**How to apply:** Keep property location controls cascading and reset downstream choices when a parent changes. Store the precise hierarchy with the property review data and publish it as the listing location after approval.
